# KeyMaster Pro - Python Mastery

Aplicacion gamificada para practicar y aprender Python tipeando codigo.

## Instalacion

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# Si keymaster.py esta vacio (tras un fallo de deploy):
python restore_keymaster.py
python keymaster.py
```

## Ruta recomendada para aprender

1. Entrenamiento 5-10 min
2. Aprendizaje -> Fundamentos (incluye huecos ____)
3. Constructor de codigo
4. Aprendizaje: estructuras -> control de flujo -> funciones
5. Desafios diarios
6. Supervivencia solo con soltura

Ver tambien LEARNING.md
